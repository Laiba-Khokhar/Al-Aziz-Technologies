# Week 4 – Day 2: Power Query & Data Transformation

## Objective
To learn how to clean and transform raw data using Power Query in Power BI and create a repeatable data-cleaning workflow.

## Dataset
Retail Sales Dataset

## Tasks Completed

- Imported the raw retail sales dataset into Power BI.
- Opened and explored the data in Power Query Editor.
- Checked data quality using data profiling.
- Removed duplicate records.
- Handled missing values.
- Changed data types.
- Split columns.
- Merged columns.
- Replaced inconsistent values.
- Created conditional columns.
- Reviewed and organized Applied Steps.
- Created a repeatable data-cleaning workflow.

## Hands-on Task

### 1. Import a Business Dataset

A student academic performance dataset was imported into Power BI Desktop.

The dataset contains information about:

- Student Name
- Quiz Marks
- Mid Term Marks
- Presentation Marks
- Final Exam Marks
- Total Obtained Marks
- Student Percentage
- Grade

### 2. Create a Basic Power BI Report

A **Student Academic Performance Dashboard** was created to provide an overview of student performance.

The report includes KPI cards, charts, a table, and an interactive slicer.

---

## Dashboard Components

### KPI Cards

The dashboard includes three key performance indicators:

- **Class Average %**
- **Highest Student Marks**
- **Lowest Student Marks**

These KPIs provide a quick overview of overall academic performance.

### Student Performance Chart

A bar chart was created to compare the **Sum of Total Obtained Marks by Student Name**.

This helps identify students with higher and lower overall marks.

### Assessment Performance Chart

A column chart was created to compare the **Assessment Average by Assessment**, including:

- Final Exam
- Mid Term
- Quiz
- Presentation

This helps analyze performance across different assessment types.

### Student Performance Table

A detailed table was created containing:

- Student Name
- Total Quiz Marks
- Mid Term Marks
- Presentation Marks
- Final Exam Marks
- Total Obtained Marks
- Student Percentage
- Grade

### Slicer

A **Student Name slicer** was added to allow users to interactively filter the report and focus on individual students.

---

## Key Insights

The dashboard provides an overview of student academic performance and allows comparison between students and different assessment types.

The report can be used to:

- Identify high-performing students
- Identify students who may need additional support
- Compare performance across assessments
- Review individual student results
- Understand overall class performance

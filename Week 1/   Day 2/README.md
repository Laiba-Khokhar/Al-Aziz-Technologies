# Week 1 – Day 2: Excel Formula Practice

## Overview

This task focuses on practicing Excel formulas and functions using the **Mini Store Business Dataset** created in Day 1.

The purpose of this task is to understand how Excel formulas can be used to analyze business data, perform calculations, apply logical conditions, summarize data, and retrieve information.


## Objective

The main objective is to gain practical experience with Excel formulas and understand how they can be applied to real-world business data.

The formulas are being added as separate columns to the existing Day 1 dataset so that the original data remains unchanged while different calculations and conditions can be practiced.

## Key Learning Outcomes

Through this task, I practiced:

* Applying logical conditions to business data
* Performing conditional calculations
* Summarizing sales data by category and other criteria
* Counting records based on specific conditions
* Calculating conditional averages
* Using lookup functions to retrieve information
* Extracting useful information from dates
* Handling formula errors
* Understanding and auditing Excel formulas



## Conclusion

Day 2 focuses on building practical Excel formula skills by applying different functions to the Mini Store Business Dataset. This provides a foundation for performing more advanced data analysis and business reporting in Excel.

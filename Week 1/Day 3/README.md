# Week 1 – Day 3: Data Cleaning and Transformation

## Overview

This task focused on cleaning and transforming a messy retail dataset using Excel and Power Query.

## Tasks Performed

* Handled missing values
* Removed duplicate records
* Removed extra spaces using TRIM
* Cleaned text using CLEAN
* Used LEFT, RIGHT, MID, FIND, and SUBSTITUTE
* Standardized text, dates, and numbers
* Applied sorting and filtering
* Added Data Validation dropdowns
* Applied Conditional Formatting
* Practiced Formula Auditing

## Objective

The objective was to transform messy raw data into a clean, consistent, and analysis-ready dataset while practicing common Excel data-cleaning techniques.


## Outcome

The raw dataset was cleaned and transformed into a structured dataset suitable for further analysis and reporting.

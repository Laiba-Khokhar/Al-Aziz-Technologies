# Mini Store Business Dataset
## Overview

This Excel dataset represents a small retail store's sales transactions. It was created to practice basic Excel skills for data analysis and data cleaning.


## Analysis Performed

Basic Excel calculations were performed, including:

* SUM
* AVERAGE 
* MAX
* MIN 
* COUNT 
* COUNTA 

## Key Results

* Total Sales: 26,450
* Average Sales: 2,645
* Maximum Sales: 5,400
* Minimum Sales: 500
* Total Transactions: 10

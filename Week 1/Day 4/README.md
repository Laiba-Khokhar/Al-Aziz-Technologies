This task focuses on using the cleaned retail sales dataset from Day 3 to create an interactive Excel dashboard.

Analyzed sales by category
Created Pivot Charts

The objective is to transform cleaned sales data into meaningful visual insights using Excel Pivot Tables, charts, and interactive dashboard features.

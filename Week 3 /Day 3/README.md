# Week 3 – Day 3: Data Cleaning with Python

## Overview

This task focused on cleaning and preparing datasets using Python and Pandas. The exercises covered common data-quality problems and techniques used in real-world data analysis.


## Hands-on Practice

The following data-cleaning operations were practiced:

- Identified and handled missing values
- Replaced missing values using `fillna()`
- Removed rows containing missing values using `dropna()`
- Detected and removed duplicate records
- Converted incorrect data types
- Identified outliers using the IQR method
- Standardized inconsistent text values
- Cleaned strings by removing extra spaces and standardizing capitalization
- Converted text dates into datetime format
- Created new features from existing data
- Replaced incorrect or inconsistent values using `replace()`
- Applied custom functions using `apply()`
- Validated data using business rules
- Created a reusable data-cleaning workflow

## Learning Outcome

Learned how to identify common data-quality issues, clean and standardize datasets, validate data, and build a reusable workflow for preparing data for analysis.

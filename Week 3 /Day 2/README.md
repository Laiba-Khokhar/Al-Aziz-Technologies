# Week 3 – Day 2: NumPy & Pandas

## Overview

This task focused on NumPy and Pandas for data analysis and data manipulation using Python. The exercises were performed in Google Colab.

## Topics Covered

### NumPy
- NumPy arrays
- Array operations
- Vectorization
- Indexing

### Pandas
- Pandas Series
- Pandas DataFrames
- Reading CSV files
- Reading Excel files
- Reading JSON files
- Selecting columns
- Filtering rows
- Sorting data
- GroupBy
- Aggregation
- Merging datasets
- Concatenation

## Hands-on Practice

A retail sales dataset was created and loaded into Google Colab using Pandas.

The following operations were performed:

- Loaded an Excel dataset using `pd.read_excel()`
- Inspected the dataset using `head()`, `shape`, `columns`, `info()`, and `describe()`
- Selected individual and multiple columns
- Filtered rows based on conditions
- Filtered data using text values
- Sorted sales data from highest to lowest
- Grouped sales data by product category
- Performed basic aggregation using `sum()`
- Created and worked with multiple DataFrames
- Practiced merging datasets
- Practiced concatenating datasets

## Dataset

The hands-on exercise used a retail sales dataset containing:

- Order ID
- Order Date
- Customer
- Product
- Category
- Region
- Quantity
- Unit Price
- Sales

## Learning Outcome

Learned how to use NumPy for numerical operations and Pandas for loading, inspecting, filtering, sorting, grouping, and manipulating structured datasets.

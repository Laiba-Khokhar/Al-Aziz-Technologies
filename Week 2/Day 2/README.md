# Week 2 – Day 2: Filtering, Aggregation & Grouping
## Overview

This task focused on filtering, aggregating, and grouping data using SQL. 
The existing `retail_analytics` database created during Day 1 was used to analyze customer, product, and sales data.

## Topics Covered

### Filtering
- Comparison operators
- WHERE
- AND
- OR
- IN
- BETWEEN
- LIKE
- NULL
- IS NULL
- IS NOT NULL

### Aggregation
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

### Grouping
- GROUP BY
- HAVING

### Conditional Logic
- CASE WHEN

## Hands-on Practice

The following analyses were performed:

- Filtered products using comparison operators.
- Combined multiple conditions using AND and OR.
- Filtered multiple categories using IN.
- Filtered prices using BETWEEN.
- Searched product names using LIKE.
- Identified missing and non-missing customer emails.
- Calculated total, average, minimum, and maximum sales.
- Counted customer and order records.
- Grouped sales by payment method.
- Used HAVING to filter grouped results.
- Created sales categories using CASE WHEN.


## Objective

The objective was to develop practical SQL skills for filtering, summarizing, grouping, and analyzing customer and sales data.

## Learning Outcome

This task provided hands-on experience in analyzing business data using SQL and helped build a strong foundation for more advanced SQL analysis.

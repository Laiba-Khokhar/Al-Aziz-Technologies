
Week 2 – Day 1: SQL Fundamentals
Overview
This task focuses on learning the fundamentals of SQL and working with a relational database using MySQL Workbench.

A small retail analytics database was created to practice basic SQL concepts and queries.

Database Structure
The database contains three related tables:

Customers – Stores customer information.
Products – Stores product details, categories, and prices.
Orders – Stores customer orders and sales information.


Week 2 – Day 3: SQL Joins & Subqueries
Overview

This task focused on combining and analyzing data from multiple tables using SQL. The retail_analytics database created in previous tasks was used.

Topics Covered
Understanding table relationships
INNER JOIN
LEFT JOIN
RIGHT JOIN
FULL JOIN concept
Multiple-table joins
Self Join
Subqueries
Nested queries
Common Table Expressions (CTEs)
UNION
UNION ALL
Hands-on Practice
Combined Customers, Orders, and Products tables.
Used joins to retrieve related customer, order, product, and sales information.
Used Self Join to compare customers from the same city.
Used subqueries and nested queries for sales analysis.
Used CTEs to organize complex queries.
Combined query results using UNION and UNION ALL.

Learning Outcome

Developed practical experience in joining multiple tables, writing nested queries, using CTEs, and performing multi-table analysis with SQL.

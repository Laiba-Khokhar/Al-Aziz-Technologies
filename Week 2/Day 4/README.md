# Week 2 – Day 4: Advanced SQL for Analytics

## Overview

This task focused on advanced SQL techniques used for business and data analysis. The `retail_analytics` database was used to perform analytical queries on customer, product, and sales data.

## Topics Covered

- Window Functions
- OVER()
- PARTITION BY
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- Running Totals
- Moving Averages
- Date Functions
- Time-Based Analysis
- Conditional Aggregation
- Query Optimization Basics
- Writing Readable SQL

## Hands-on Practice

- Calculated overall and partitioned sales using window functions.
- Numbered and ranked orders using `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- Created running totals and moving averages.
- Extracted year, month, and day from order dates.
- Performed time-based sales analysis.
- Used conditional aggregation for payment-method analysis.
- Applied basic SQL optimization and readability practices.
- Created reusable analytical queries for business analysis.
- Ranked customers based on their total sales.


## Learning Outcome

Developed practical experience with advanced SQL analytics, window functions, ranking, time-based analysis, conditional aggregation, and writing efficient and readable SQL queries.
